# 현무갤러리

1층 TTC(Table Talk Cafe) ZONE · 2층 고미술품 작품 경매장 사업계획 템플릿.

`dist/index.html`과 같은 폴더의 CSS, JS, assets를 함께 사용합니다. Netlify는 `dist`를 게시 폴더로 지정합니다.

사진 2장·영상 3편과 제공된 TTC 사업계획/프로그램 기획/브랜드 소개를 반영했습니다. 현장 영상은 재생용 압축본이며 원본은 변경하지 않았습니다.

실제 TTC Connect 인증·채팅·신고·직원 호출 및 경매 응찰·결제는 이 안내 템플릿과 별도의 운영 시스템입니다. 면적·개장일·투자비·요금·수익률·작품 진위는 확정 전입니다.
